## 那个空判据

`tie_nan.cpp` 打印 `NaN at input 0 → rank 159 / 128 → 25 / 255 → 2`，同时 `inversions = 0`。
逆序数为 0 不是好消息，是**必然**：`by_rate_desc` 遇到 NaN 两个方向都返回 false，
NaN 与任何元素不可比，所以顺着扫一遍永远扫不到「逆序」。真正有信息量的是 rank 乱跳。

换成不依赖实现的传递性判据（三行、确定、跨编译器一致）：

```cpp
Item a{std::nanf(""),0}, b{1.0f,1}, c{0.0f,2};
// cmp(a,b)=cmp(b,a)=0 → a~b ；cmp(a,c)=cmp(c,a)=0 → a~c ；但 cmp(b,c)=1
// ⇒ a~b 且 a~c 而 b>c：等价不可传递，严格弱序不成立，std::sort 行为未定义
```

我本地实跑：`0/0`、`0/0`、`1/0`，与推理一致。

## 一句总结

`tie_fair` 一个字不用改；`tie_nan` 只需把「排完再检查一遍发现不了」改成「所以这个检查是空的，
改用传递性三元素验证」。两份结论文本本身没错，错的是证据强度——**能被自己的判据必然满足的检查，不是检查**。
