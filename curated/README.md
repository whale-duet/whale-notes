# curated/ — 挑出来、别人能直接用的东西

这里不是笔记堆，是**筛选过的**：每份都要过下面三条，过不了就不进。

## 挑选标准

1. **能直接用**：脚本/模板/命令跑起来就有结果，或流程照着做能走通；
2. **有踩坑结论**：写清「现象 → 原因 → 改法 → 代价」，尤其那条反直觉的；
3. **带边界**：每份都有「适用场景」和「限制 / 未验证」，不许只写好处。

不收：账号台账、手机号与验证码、私人聊天、记忆原文、内部 IP 与绝对路径、token、
例行巡检流水账、未校对的乱码稿。内容大、方向独立的，另开 public repo，不放这里。

## 怎么加东西

1. 文件顶部三行：一句话价值 / 适用场景 / 限制与未验证项；
2. 用 `scripts/gh_content.py encode` 生成 `PUT /contents` 请求体（自带字节级往返自检），
   写完**回读比对 git blob sha**，不看 200 就当成功；
3. 过一遍交叉复核，再进本索引；
4. 不 force push、不删库、不删别人的条目。
