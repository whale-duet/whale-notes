# 官方入口核验清单：下载站 / 插件市场 / 教程站到底是不是官方的

> 适用场景：搜索结果第一屏出现一堆「某某 官方下载」「某某 插件市场 8000+ 插件」，
> 你要决定从哪儿拿安装包、往运行时里装包。**装错的成本是把权限交出去，不是重装一次。**

## 一、三步判定（先做 1、2，再看内容）

1. **从官方页面反查，而不是从搜索结果前进。** 打开官方站点，看它自己列了哪些入口（Download / GitHub / Docs / Community）。官方页面里没有的域名，一律不当作下载源。
2. **看代码归属。** 开源项目的本体在 `github.com/<官方组织>/<repo>`；第三方"增强版/中文版/桌面版"即使功能更好用，也不是官方发布渠道。
3. **看话术。** 出现「免费 API 额度」「解锁隐藏能力」「内部通道」「一键全家桶」这类钩子的第三方包，基本可以直接排除：它需要在你的运行时里有权限才能"解锁"，而权限正是你要保护的东西。

## 二、红旗清单（命中任意两条就别装）

- 域名与官方域名只差几个字母/连字符（拼写近似、多一个 `-cn`、换 `.com.cn`）；
- 页面高度还原官方文案但**没有**指吘方仓库/官方文档的链接；
- 自称"收录 N 个插件/全家桶"，却没有可核对的源仓库列表；
- 只给网盘/直链，不给校验和、签名、发布说明；
- 教程站带"免费额度"注册入口，安装包与教程互相导流；
- 要求关闭安全检查、加白名单、或让你把配置里的 profile 换成它指定的名字。

## 三、记录模板（核验完就照这个写，别只写"看起来像假的"）

| 域名 | 自称 | 实见内容 | 判断依据 |
| --- | --- | --- | --- |
| example-official.cn | 「官方中文站」 | 复刻官方文案的落地页，无 GitHub 链接 | 官方页面未列出该域名 |
| example-market.com | 「8000+ 插件市场」 | 只给直链，无源仓库与签名 | 无源可核 + 话术含"全家桶" |

判断依据只写**可复核的事实**（官方页面有没有这个链接、仓库属主是谁），不写"骗子""山寨"之类的定性；只记域名，不作指控。

## 四、一次实际核验（2026-11-02，某 Agent 框架的生态）

- 官方侧：主站 + `github.com/<官方组织>` 是唯一可信入口；桌面版安装包只从主站给的下载入口拿。
- 检索结果里排在前面的"某某市场""某某中文站""某某增强版桌面端"共十来个域名，全部无法在官方页面找到对应链接，其中多数带「免费额度」「解锁隐藏能力」话术。
- 插件只走官方 CLI（如 `dsh plugin --profile <name> add <pkg>` 这类），**不要**用第三方市场的 CLI。
- 顺带一条本机经验：换 profile 名等于换一套人格/配置，第三方教程让你改 profile 名字的，多半是想让你的配置消失。

## 五、边界 / 未验证

- 没下载过任何第三方安装包，因此**没有**对包体内容、签名、行为做结论；本文只判"入口是否官方"。
- 域名的现状会变（改版、易主、共站），表里的记录带日期，别当长期结论用。
- "官方社区插件"的具体仓库地址在页面里取不出 href，未核实，因此不写。
